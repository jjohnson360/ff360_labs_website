# ff360_labs

> Always building something new.

ff360_labs designs and builds websites, interactive experiences, 3D work, and creative software — for small businesses, artists, and anyone with an idea that doesn't fit a template. 

This repository contains the front-end source code for the official studio website.

## 🛠 Tech Stack & Architecture

This project is built as a lightweight, high-performance static site prioritizing speed and zero-dependency maintenance.

*   **HTML5 / CSS3:** Semantic markup with custom CSS properties for dynamic theming (blueprint grids, metallic gradients).
*   **Typography:** Hosted via Google Fonts using *Fraunces* (Serif), *Inter* (Sans-Serif), and *JetBrains Mono* (Monospace).[cite: 5]
*   **JavaScript:** Vanilla JS utilized for the continuous waveform animation and dynamic background position rendering on metallic text elements.[cite: 5]
*   **Form Handling:** Serverless form submissions routed through the `@formspree/ajax` package.[cite: 5]
*   **Hosting:** Configured for automated deployment via GitHub Pages.
